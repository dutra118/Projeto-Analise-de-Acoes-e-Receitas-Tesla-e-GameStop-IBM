# Projeto: Análise de Ações e Receitas – Tesla e GameStop | IBM
Projeto desenvolvido durante o curso de Data Science da IBM, com o objetivo de coletar, manipular e visualizar dados históricos do mercado financeiro, analisando a relação entre o preço das ações e a receita das empresas Tesla e GameStop.

Durante o desenvolvimento, foram aplicadas técnicas de extração e análise de dados, incluindo:
Coleta de dados financeiros: utilização da biblioteca yfinance para obter dados históricos dos preços das ações.
Web Scraping: extração de informações sobre as receitas trimestrais das empresas utilizando Requests e BeautifulSoup.
Manipulação e tratamento de dados: utilização da biblioteca Pandas para organizar, limpar e estruturar os dados em DataFrames.
Visualização de dados: criação de gráficos utilizando Matplotlib para analisar a evolução histórica dos preços das ações e das receitas das empresas.
Análise exploratória: comparação entre o comportamento das ações e o desempenho financeiro das empresas ao longo do tempo.
Tecnologias e ferramentas: Python, Pandas, yfinance, Requests, BeautifulSoup, Matplotlib e Jupyter Notebook.
